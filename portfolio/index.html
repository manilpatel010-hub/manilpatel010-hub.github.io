PROJECT 01

Retail Sales & Profitability Optimization

SQL Excel Power BI
Problem Retailer lacked visibility into low-margin products, leading to inefficient pricing and inventory decisions.
Approach SQL-based sales performance analysis; Excel modeling for margin calculations; Power BI dashboards for leadership review.
Solution Built profitability dashboards tracking product-level margins, category trends, and inventory turnover KPIs.
📈 Delivered pricing & inventory recommendations that improved profit strategy insights for leadership decision-making.
PROJECT 02

Loan Origination System Optimization

SQL Excel Power BI Jira
Problem Manual loan origination workflows created bottlenecks, compliance gaps, and processing delays in the banking pipeline.
Approach Produced BRD, user stories, and acceptance criteria using Agile. Mapped AS-IS / TO-BE processes with draw.io. Tracked KPIs in Power BI.
Solution Redesigned loan workflow with automation touchpoints; delivered documentation supporting system implementation.
⚡ Enabled ~70% automation in loan processing, reducing manual effort and improving compliance tracking.
PROJECT 03

Customer Churn Analytics

SQL Power BI DAX
Problem Business had limited visibility into why customers were leaving — no segmentation, no churn drivers, no retention strategy.
Approach Analyzed 10,000+ customer records in SQL to identify behavioral patterns. Built DAX-powered segmentation dashboards in Power BI.
Solution Identified key churn drivers including ~40% inactive user segment; built interactive retention analytics dashboard.
🎯 Insights informed a targeted retention strategy with projected 15–20% churn reduction opportunity.
